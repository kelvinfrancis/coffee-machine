# ☕ Coffee Machine Program

A fun and interactive **Python console app** that simulates a real coffee machine!  
Choose your drink, pay with virtual coins, and watch the machine make your coffee — all while tracking resources and profit.  

---

## 🚀 Features

✅ Choose between **espresso**, **latte**, or **cappuccino**  
✅ Tracks available **water**, **milk**, and **coffee**  
✅ Accepts coins: **quarters**, **dimes**, **nickels**, and **pennies**  
✅ Calculates change and updates profit  
✅ View a detailed **report** of current resources  
✅ Turn off the machine with the `off` command
